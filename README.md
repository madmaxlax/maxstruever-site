# Max Struever personal website

Source for [maxstruever.com](https://maxstruever.com). It's a React 19 + MUI 9 single-page app built with Vite and hosted on Netlify.

- Netlify dashboard: [app.netlify.com/projects/maxstruever/overview](https://app.netlify.com/projects/maxstruever/overview)
- Repo: [github.com/madmaxlax/maxstruever-site](https://github.com/madmaxlax/maxstruever-site)

## Quick start

```bash
fnm use        # Node 26, from .nvmrc
npm install
npm run dev   # http://localhost:3000
```

`npm run build` writes to `dist/`. `npm run preview` serves that build locally.

Architecture, content locations and deploy notes are in [AGENTS.md](./AGENTS.md).
